# signarol

Signarol bridges the gap between recruiters and engineering talent. Recruiters can discover and evaluate qualified professionals through structured assessments and intelligent candidate ranking, while engineers can sharpen their skills with practice interviews, coding challenges, and career-focused learning resources.

This repo is organized into separate frontend and backend workspaces.

## Frontend

The React + Vite app lives in `frontend`.

```bash
cd frontend
npm install
npm run dev
```

## Backend

The backend workspace lives in `backend`. It currently contains the server-side folder scaffold for future API, services, middleware, models, workers, and tests.
